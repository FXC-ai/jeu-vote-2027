Comment lire ces scores ?

Affinité : 100 % lorsque toutes les notes sont identiques.

Concordance : même catégorie de réponse (positive, négative ou neutre).

Opposition : réponses de signes opposés.

Neutralité divergente : un profil répond 0, l’autre non.
