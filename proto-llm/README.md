# Jeu-vote.fr — prototype HTML

## Ouvrir le prototype

Ouvrir `index.html` dans un navigateur. Le prototype fonctionne en local, sans serveur ni installation.

## Scénario de démonstration

Sur la page « Questionnaires transversaux », ouvrir les résultats du questionnaire transversal 03, puis utiliser la comparaison en saisissant le login fictif `fxc-ai`.

## Fichiers

- `index.html` : version la plus récente, avec le formulaire de comparaison corrigé.
- `versions/` : toutes les versions HTML créées pendant la conception, à titre d'archive et de comparaison.

Les données présentées sont fictives ; aucun backend n'est connecté.
